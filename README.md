# Semre Demssie - Professional Portfolio

A modern, professional portfolio website built with Vue.js 3, Vite, and Tailwind CSS. Features real tech icons, smooth animations, GitHub stats integration, and a fully responsive design.

## ✨ Features

- 🎨 Modern, professional design with gradient accents
- 🌓 Dark mode toggle with localStorage persistence
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎭 Smooth scroll animations with AOS
- 💼 Real technology icons using Iconify
- 📊 Live GitHub statistics integration
- 🎯 Organized skills by category (Frontend, Backend, Mobile & Tools)
- 🚀 Fast performance with Vite
- ✉️ Contact form with validation
- 🎨 Animated background effects

## 🛠️ Tech Stack

- **Framework:** Vue.js 3 (Composition API)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Iconify Vue
- **Animations:** AOS (Animate On Scroll)
- **Font:** Inter (Google Fonts)

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Sections

1. **Hero** - Eye-catching introduction with animated background and social links
2. **About** - Professional background with stats and highlights
3. **Skills** - Categorized tech stack with real icons (Frontend, Backend, Mobile & Tools)
4. **Projects** - 6 featured projects with detailed descriptions and tech badges
5. **GitHub Stats** - Live GitHub activity, top languages, and contribution streak
6. **Contact** - Contact information and functional form
7. **Footer** - Copyright and credits

## 🎨 Customization

### Update Personal Information

Edit the component files to customize:

- **Hero.vue** - Name, title, bio, social links
- **About.vue** - Professional background and highlights
- **Skills.vue** - Add/remove skills and categories
- **Projects.vue** - Update project details, links, and tech stacks
- **Contact.vue** - Email and contact information

### Change Colors

Modify `tailwind.config.js` to customize the color scheme.

### GitHub Stats

The GitHub stats automatically pull from username `santa36264`. To change:
- Edit `src/components/GitHubStats.vue`
- Replace `santa36264` with your GitHub username
